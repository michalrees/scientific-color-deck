# Changelog

## 0.5.3 — 2026-10-19

- Organize the chart gallery exclusively by chart family, with search and pagination.
- Remove source filters, source catalog buttons and source badges from cards; preserve source attribution in details and data.


## 0.5.2 — 2026-10-19

- Merge the chart gallery’s Personal and Markdown filters into Author; retain all 60 author-catalog entries and the Origin/nature-figure filters.
- Rename the chart gallery shortcut, summary and screenshot-source labels consistently while retaining underlying provenance.


## 0.5.1 — 2026-10-17

- Add a Scientific Plotting status bar shortcut that opens the existing color deck.
- Activate after startup so the shortcut is available before opening the command palette; the item can be hidden from the native status bar menu.


## 0.5.0 — 2026-10-17

- Add a separately attributed Origin catalog: 20 categories and 217 type/variant records from the specified Graphing overview page.
- Bundle original deterministic Canvas illustrations with bilingual names, data hints and source links; no upstream images or templates are copied.
- Add catalog/category search, 36-card pagination, enlarged previews and PNG saving.
- Retain Personal and all 100 palettes; move gallery listeners outside tab activation to avoid duplicate listeners and filter options.


## 0.4.0 — 2026-10-17

- Add side-by-side two-color comparison, swap, validation and persisted inputs.
- Add a searchable 156-name Matplotlib/CSS4 reference table with HEX/RGB, copy and compare actions.
- Move vision checks after the chart gallery in the five-tab navigation.


## 0.3.0 — 2026-10-17

- Expand the library to 100 palettes with 37 ColorBrewer/D3 and 25 Matplotlib schemes.
- Add source, license, version and sampling records, cyclic/miscellaneous filters and an Open-source collection.
- Export continuous palettes as colormaps instead of categorical cycles.
- Preserve all 32 Personal palettes and the 60-chart gallery.

## 0.2.0 — 2026-10-16

- 新增 Personal 分类：24组个人参考配色、6套 nature-figure 语义色表及2套默认循环。
- 增加配色来源/类型/名称/色值筛选及色号冲突说明。
- 新增“图表图鉴”入口，60类原创演示缩略图、来源筛选、点击放大和当前配色重绘。
- 增加统计口径、完整数据、上游提交及许可证记录。

## 0.1.1 — 2026-10-16

- 新增三组用户参考图配色（8 / 6 / 5 色），按标注色号和顺序整理。
- 新增独立 HEX / RGB 清单与 JSON 数据，界面显示参考图来源说明。

## 0.1.0 — 2026-10-16

- 新增颜色代码查询、透明度预览与选中色值入口。
- 新增本地图片像素取色及近似主色提取。
- 新增六组配色及 Python、R、MATLAB、CSS、JSON 代码导出。
- 新增配色和图片的色觉缺陷 / 灰度预览、PNG 预览导出与 WCAG 文字对比度检查。
- 提供回归检查、本地浏览器预览及 VS Code F5 调试配置。
